# mango palette (keep this)

Taken from the wallpaper: teal from the roofs, gold from the trim. Used by
config.conf, waybar.css, mako, foot.ini and pg-mango-menu.

| name  | hex     | used for                                  |
|-------|---------|-------------------------------------------|
| base  | #0e141a | background: root, bar, menu, notifications, terminal |
| shade | #1b252d | focused title in the bar, menu selection  |
| line  | #2a3640 | unfocused borders, separators             |
| text  | #e6edf0 | main text                                 |
| dim   | #8fa3ad | secondary text, idle tags                 |
| teal  | #5fd4c4 | accent: focused border, active tag, cursor |
| gold  | #f2c46d | secondary accent: maximized, sticky, warnings |
| rose  | #ef6b73 | urgent, critical battery                  |
